Plaza documentation

Install Plaza, understand its package sources, or build it from source.

Install Plaza on Debian or Orbis OS

Download the matching .deb package from the GitHub releases page, then open it with the system software installer. The amd64 package works on both Intel 64-bit and AMD64 PCs; ARM devices can use arm64 or armhf when supported by their OS. The i386 package is for legacy 32-bit compatibility on amd64 systems, not a supported standalone Debian 13 install. Plaza's in-app updater can download newer Plaza releases and hand the package to PackageKit for system-authorized installation.

Plaza requires Flatpak for Flatpak installs. Native APT packages and self-updates require PackageKit and its APT backend. Flatpak app installs use the current user's installation; Plaza can add the official Flathub remote the first time an app needs it.

Using Plaza

Discover and install

Search the bundled starter catalog or browse metadata from configured Flatpak remotes. Select a source when multiple compatible sources are listed, then install from the app card. Plaza verifies the official Flathub setup and does not silently substitute an app or repository.

Installed apps and updates

The Installed page scans desktop entries from Flatpak and the system. Update checks use Flatpak and the supported system package manager. A Plaza release update is downloaded from the official GitHub releases API, checked against the published SHA-256 digest, and installed through PackageKit; restart Plaza afterward.

Sources and privacy

Flatpak sources are stored for the current user. Add a repository with an HTTPS .flatpakrepo file and a signing key. The bundled SQLite app catalog works offline; a PostgreSQL service is not required. Update checks contact the public GitHub Releases API.

Build from source

Install Qt 6.5 or newer development libraries, the Qt SQLite SQL plugin, Kirigami, libflatpak, zlib, CMake, Ninja, and a C++20 compiler.

cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
ctest --test-dir build --output-on-failure
