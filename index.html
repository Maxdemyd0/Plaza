Free and open source · MIT licensed · Flatpak installs stay in your user account

A simpler way to manage apps

Plaza brings app discovery and installation into one familiar desktop experience, while leaving each package manager in charge of its own software.

Discover and search

Browse a bundled starter catalog and enrich it with app listings from configured Flatpak sources.

Install with progress

Install Flatpak apps directly in Plaza, with progress, cancellation, and launch controls in the app card.

See what is installed

Match installed apps to store listings where possible, while keeping their original launchers and ownership.

Keep software current

Check Flatpak and supported system-package updates, and get notified when a Plaza release is available.

Sources stay transparent

Review and manage user Flatpak remotes. Plaza does not silently substitute a different source.

No catalog server setup

The starter catalog is bundled with Plaza. PostgreSQL is not required to open the app or browse its starter listings.

Install without the scavenger hunt

Plaza uses the package sources that fit the current system and hands privileged package operations to the operating system.

  1. Open Plaza and find an app in Discover.
  2. Choose Install and follow the in-card progress.
  3. Open the app from Plaza when it is ready.
